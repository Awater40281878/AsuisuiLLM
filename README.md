# AsuisuiLLM

一個以本機運算為預設的個人 AI 助理。目標是逐步提供對話與檔案搜尋、工作管理、本機語音，以及可審查、可回復的長期記憶。

## 開發狀態

目前已有可執行的命令列原型，支援本機 Ollama 對話、對話搜尋及工作清單。圖形介面、語音和 Git 記憶仍在後續階段。

## 立即使用

先確認 Ollama 已啟動，並安裝模型：

```powershell
ollama pull qwen3:8b-q4_K_M
python app.py status
python app.py chat 你好，請用繁體中文自我介紹
python app.py task-add "整理 AI 開發計畫" --due 2026-11-30
python app.py task-list
python app.py search "自我介紹"
```

程式只用 Python 標準函式庫，不需 pip 套件。對話與工作預設儲存在本 repo 的 `data/assistant.sqlite3`，且 `data/` 已被 Git 忽略；可用 `ASUISUI_DATA_DIR` 改變資料目錄，`ASUISUI_MODEL` 改變模型名稱。

## 第一個可交付版本

1. 本機文字聊天：連接本機模型服務，清楚顯示服務狀態與模型名稱。
2. 本機對話保存與搜尋：SQLite、全文索引；資料目錄不進 Git。
3. 工作管理：新增、查詢、完成與期限，不讓模型直接改資料庫。
4. 按鍵語音：本機語音辨識與語音合成；常駐喚醒延後評估。
5. 記憶版本管理：先產生候選變更與差異，經使用者核准後才提交本機 Git；提供回復與來源追蹤。

## 本機安全預設

- 對話、匯入檔案、SQLite、向量索引、模型權重與語音錄音皆放在本機資料目錄，不加入版本控制。
- 不把祕密、原始對話或私人文件自動寫入記憶。
- Git 遠端推送、網路搜尋、外部日曆整合與常駐麥克風都先保持關閉。
- Git 歷史提供變更追蹤，不是備份；重要資料仍需另行備份。

## 硬體基線（待在開發機重新確認）

依目前提供的資訊：Windows、32 GB RAM、GeForce RTX 3060 12 GB VRAM，以及 D 槽 NVMe SSD。這足以評估本機中小型量化語言模型與本機語音模型；實際模型選擇需以可用記憶體、速度、中文品質和模型授權測試後決定。

## 技術選型原則

優先採用 Windows 上容易安裝、能離線運作、授權清楚且可以替換的元件。第一階段先驗證本機模型服務與語音模型；在這些決策及硬體確認前，不固定綁定特定模型或建立遠端同步。
